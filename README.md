# React Ecommerce Site

A simple ecommerce storefront built with React and classic Redux.

## Overview

This project demonstrates a basic online store using React, React Router, and Redux for state management. It uses the older Redux patterns with actions, reducers, and a single store instead of modern Redux Toolkit abstractions.

## Features

- Product listing page
- Product details page
- Shopping cart with add/remove item support
- Redux store for cart state management
- Simple responsive layout for desktop and mobile

## Tech Stack

- React
- Redux
- React Router
- JavaScript
- CSS

## Getting Started

1. Install dependencies

```bash
npm install
```

2. Start the development server

```bash
npm start
```

3. Open the app

Navigate to `http://localhost:3000`

## Available Scripts

- `npm start` - runs the app in development mode
- `npm test` - launches the test runner
- `npm run build` - bundles the app for production

## Notes

This project uses the older Redux setup with separate action creators and reducers. It is a good reference for understanding classic Redux architecture in a small ecommerce app.
